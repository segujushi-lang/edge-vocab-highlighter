# 拾词 · 网页生词荧光笔

一个可直接侧载到 Microsoft Edge 的 Manifest V3 扩展。保存陌生英文单词后，它会在之后访问的网页中自动高亮；点击高亮即可查看缓存的中文翻译。

## 安装到 Edge

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开页面左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目文件夹，也就是包含 `manifest.json` 的目录。
5. 建议在扩展菜单中把“拾词”固定到工具栏。

安装或更新代码后，若已经打开网页，请刷新该网页一次，让内容脚本开始工作。

## 使用方式

- 划词保存：在普通网页中选中一个完整的英文单词，点击浮出的“保存并高亮”。
- 右键保存：选中单词后右键，选择“保存‘…’并高亮”。
- 查看翻译：单击黄色高亮的单词。
- 快速移除：在单词释义卡片中点击“移出词库”。
- 管理词库：点击 Edge 工具栏中的“拾词”，可以添加、搜索、修改翻译、重试翻译或删除单词。
- 暂停高亮：关闭弹窗右上角的开关；词库不会丢失，再次打开即可恢复。
- 清空词库：使用弹窗底部的“清空词库”。

## 工作原理

- 词库保存在 `chrome.storage.local` 中，所有网页标签页会自动同步更新。
- 匹配不区分大小写，并只匹配完整英文单词，避免把 `cat` 错误标在 `category` 中。
- 动态网页通过 `MutationObserver` 增量处理，适用于多数 SPA 和无限滚动页面。
- 首次保存且未手工填写中文时，后台脚本调用 MyMemory 获取翻译并缓存；以后查看不再重复请求。
- 高亮脚本会跳过输入框、可编辑区域、代码块、脚本和样式节点，尽量不干扰原网页。

## 已知限制

- Edge 内部页面（如 `edge://settings`）、扩展商店页面等受浏览器安全规则保护，扩展不能注入高亮。
- 新单词的自动翻译需要网络；翻译服务不可用时，单词仍会保存，可以稍后重试或手工填写中文。
- 免费翻译结果可能不适合特定上下文，可在词库中直接修改。
- 按住 Ctrl、Command、Shift 或 Alt 点击高亮单词时，会保留网页原本的点击行为。

## 本地验证

项目不需要安装任何依赖。若系统已安装 Node.js，可运行：

```powershell
npm test
npm run check
```

## 文件结构

```text
manifest.json      Edge 扩展声明
background.js      右键菜单、词库存储和翻译请求
content.js         划词按钮、页面高亮和释义卡片
content.css        网页荧光笔样式
popup.html/css/js  词库管理弹窗
shared.js          单词规范化、匹配和数据清洗工具
tests/             零依赖自动化测试
PRIVACY.md         数据与网络请求说明
```
